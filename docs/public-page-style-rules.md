# Public page checks

Preserve original WordPress content, images, layouts and filtering keys. Every category must query the original archive and display genuine empty results when appropriate.

Check button and link colours in normal, hover and keyboard-focus states. Navy buttons require bright white text with selectors strong enough to override shared anchor styling. Light blue hover backgrounds require navy text.

Services video uses the same original YouTube iframe. Keep a visible light blue gradient frame with equal 4px padding, no white header strip, no surrounding popup panel, no external YouTube link. Place the close control outside the frame. The opening control must remain visible against the hero photograph.

Keep immutable preview assets across builds so already-open pages do not lose styling. Verify refreshed pages after restarting the preview.

Footer headings must remain bright white on navy on every page. Use scoped shared-footer selectors that override page heading rules, including detail templates.
